GST2 Streaming Terrain

This GitHub Pages site serves static terrain streaming data for VRChat from sakusdev/map-source.

Fuji legacy region

  • /data/pc/XX_YY.jpg — PC imagery
  • /data/quest/XX_YY.jpg — Quest imagery
  • /data/dem/XX_YY.gst2 — 129×129 runtime DEM
  • /data/near/... — near-detail imagery

Regional DEM streaming

  • /data/regions/index.json — region coverage index
  • /data/regions/kanto/manifest.json — Kanto grid metadata
  • /data/regions/kanto/dem/XX_YY.gst2 — Kanto 4 km / 129×129 DEM tiles

Kanto coverage is approximately 138.34–141.01°E, 34.94–37.20°N (60×63 = 3,780 supertiles).

Data attribution

VRChat clients consume editor-generated VRCUrl entries; the region index is intended for the next region-paged streaming architecture.
