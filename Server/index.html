GSI Streaming Terrain v2

This GitHub Pages site serves static terrain streaming data for VRChat from sakusdev/map-source.

  • /data/pc/XX_YY.jpg — PC imagery
  • /data/quest/XX_YY.jpg — Quest imagery
  • /data/dem/XX_YY.gst2 — runtime DEM
  • /data/manifest.json — build metadata

Data attribution

The VRChat world uses editor-generated VRCUrl entries and does not depend on this page itself.
